## Game data

The SCI0 EGA game titles that Roger supports (Space Quest III, Quest for
Glory I EGA) are commercial software with their own, separate licenses.

- Game data files (resource archives, executables, audio) are **not**
  included in this repository and are **not** covered by the GPL grant.
- Users must obtain game data through a lawful channel (for example, a Steam
  or GOG purchase) and are responsible for complying with the applicable
  license terms.
- Roger reads the game data at runtime; it does not modify or redistribute
  those files.

## Generation cache

The generation cache (`<gameid>-roger/cache/`) is produced by processing the
user's own game data through the in-engine OMYAC pipeline at runtime, on the
user's machine.  Cache files are:

- Derived artifacts; they contain no creative content that is independent of
  the game data they were generated from.
- Not distributed with or committed to this repository.
- Regenerable at any time from the original game data.

## Fonts

Roger's UI renderer loads fonts from ScummVM's own `fonts.dat` archive, which
ScummVM ships as part of its standard distribution.  The fonts used
(`GoMono-Regular.ttf`, `LiberationSans-Regular.ttf`, `NotoSans-Regular.ttf`
and others) are bundled by ScummVM under their respective open-source licenses
(Go fonts: BSD; Liberation and Noto fonts: SIL Open Font License) as described
in `gui/themes/fonts/README`.  No font files are stored inside
`engines/sci/roger/` or anywhere else in this repository outside of the paths
already present in upstream ScummVM.

## Test fixtures

The unit test fixtures under `test/sci/roger/fixtures/` are small synthetic
PNG files generated by the scripts in that directory (`gen_fixtures.py`,
`gen_overlay_fixtures.py`).  They are not derived from game data and do not
contain any proprietary content.
