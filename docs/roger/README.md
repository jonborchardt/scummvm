# Roger — fork-maintenance and upstreaming documents

This directory holds the upstream-facing and fork-maintenance documentation
for the Roger art-enhancement system (`engines/sci/roger/`).

User documentation lives in [docs/roger.md](../roger.md). Developer
orientation is in [engines/sci/README.md](../../engines/sci/README.md) and
[engines/sci/roger/README.md](../../engines/sci/roger/README.md).

## Documents

| Document | Purpose |
|----------|---------|
| `FORK_AUDIT.md` | Inventory of the full diff vs upstream `origin/master` (re-measured 2026-07-11) |
| `UPSTREAMING_PLAN.md` | Strategy for reshaping the diff into upstreamable PRs |
| `PR_PLAN.md` | Concrete PR slices and their ordering |
| `FORK_MAINTENANCE.md` | How the fork tracks upstream long-term |
| `DATA_LAYOUT.md` | On-disk layout of game data and the generation cache |
| `LEGAL.md` | Licensing review (GPLv3+, no game assets in-repo) |
